# tc-like-mis-survival

「tc-like」取自東清老師名稱的趣味命名，供 MIS 同學共用的 AI 學習輔助指令，適合「申論題＋名詞解釋」考試及喜歡課堂互動的老師。

## 使用方法
1. 將 `SKILL.md` 提供給你使用的 AI 工具，請它依內容執行；若工具支援自訂 Skills，可依該工具規範安裝或貼上。這份檔案不保證可直接安裝於所有平台。
2. 上傳課本章節 PDF、Word 講義／筆記，或貼上章節重點；並指定輸出格式：Artifact 網頁、Word 或 PDF（沒指定時 AI 會先問）。
3. 貼上以下指令：

> 請按照 SKILL.md 的規則，針對我上傳的 MIS 第 X 章，設計適合全班公開提問的 3～5 分鐘互動流程，包含自然開場、老師可能的反問、追問，以及申論題與名詞解釋的複習方向。只根據提供教材提出有根據的問題；不要宣稱能預測必考題。

## 內建第二章素材
包含《資訊管理的經濟面觀點》的平台經濟、網路效應、群眾外包、共享經濟、維基經濟、區塊鏈、金融科技、訂閱及長尾經濟等參考提問。

## 分享提醒
本工具是協助全班公平地理解教材與評量期待；不是考題洩漏或出題機率預測工具。AI 產生的範例請核對手上的教材版本。
